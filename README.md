One sentence, up to 200 characters, about the best advice I ever received.

`main.py` writes the sentence deterministically to `entry.txt` — no input,
no network, no randomness. Run it with `MAKEFUN_OUTPUT_DIR` set to the
directory where `entry.txt` should land (default `/output`).
